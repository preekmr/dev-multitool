Stop alt-tabbing to online converters.

Every developer has a bookmark folder of "JSON formatter", "base64 decode" and "jwt.io". Dev Multitool puts all of them where your text already is — and keeps your tokens and payloads on your machine.

Right in the editor

Command Palette, a grouped picker on Cmd+Alt+Shift+D, or the right-click menu. Results replace your selection — undo with Cmd+Z.

Your text stays local

Everything runs inside VS Code. JWTs, API payloads and config never leave your machine — no web service in between.

Multi-cursor aware

Each selection is processed on its own. Put ten cursors on ten Base64 values and decode them all at once.

Bind anything to a key

Every tool is a real command. Map JSON Format to Cmd+Alt+J, or bind Repeat Last Tool and fly.

Three steps. Zero context switches.

  1. 01

    Select text

    Highlight a value, use several cursors, or select nothing to work on the whole file.

  2. 02

    Pick a tool

    Type base64, json format or jwt in the Command Palette — every tool is listed as Multitool: ….

  3. 03

    Get the result

    In place, in a new tab (JWT decode, URL parse), or as a notification with a Copy button (hashes, counts, validation).

Built for keyboard people.

Every tool has a command ID, so any of them can live on a shortcut. Pair that with Repeat Last Tool and the conversions you do fifty times a day become one chord.

  • Run Tool (Result in New Tab) keeps the original text untouched.
  • Formatters follow your editor — indentation is auto, tab, or any number of spaces.
  • Clear errors with line and column for invalid JSON and XML.
keybindings.json
[
  { "key": "cmd+alt+j", "command": "multitool.json.format" },
  { "key": "cmd+alt+b", "command": "multitool.base64.decode" },
  { "key": "cmd+alt+r", "command": "multitool.repeatLastTool" }
]

Privacy you can read in one screen.

Your text is processed locally and never sent anywhere. Anonymous usage telemetry helps find bugs, and it follows VS Code's own telemetry.telemetryLevel — set it to off and nothing is sent.

Read exactly what is collected →
Never sent
Your text or selections, error messages, file names, paths, workspace names, IP-based location
Sent, anonymously
Tool id, duration, success or error type, extension and VS Code version, OS
